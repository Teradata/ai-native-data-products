# Migration note: 1.1.0

Type: minor, additive. No existing surface is removed, renamed or changed in meaning.

## What changed

| Change | Detail |
|---|---|
| New release bundle | `release/v1.1.0/` publishes the metadata schema, access surface, discovery roles, binding index, example index and conformance-check index for this version |
| New metadata table | `standard_declaration` in the Semantic module: one row per implemented component (the standard, each deployed module, each applied pattern) with its platform and standard version |
| New access view | `v_standard_declaration`, generated from the table |
| New manifest column | `data_product_manifest.standard_version`, added as the last column, so existing consumers that select columns by name or position are unaffected |
| New check | `comment-coverage`: a catalogue-wide sweep for any schema, table, view, function or column with no comment (Postgres and Teradata) |
| Comment gaps closed | Views, view columns, functions and schemas in rendered Postgres products now carry comments |
| Corrected comment | The comment on the manifest column `product_version` now says it is the product's own published contract version |

## What a deployment must do

| Platform | Action |
|---|---|
| postgres | Re-render and apply, or add the `standard_declaration` table and insert the rows from the registration template, then replace the manifest view. A deployment that does nothing keeps working; its manifest simply has no `standard_version` and the declaration view does not exist |
| teradata | Nothing is required. The comment-coverage sweep is available in `implementation/teradata/patterns/validation/comment-coverage.sql` |
| duckdb | Nothing is required in this release. The declaration, the comment-coverage check and the comment fixes are not yet ported to the Jinja binding |

## What an agent should do

Read `data_product_manifest.standard_version` when present. When it is null or the column is
absent, treat the deployment as implementing 1.0.0 and read no more into it than the 1.0.0 surface
provides.
